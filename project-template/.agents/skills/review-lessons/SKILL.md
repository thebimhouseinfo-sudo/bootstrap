# review-lessons

## Procedure
1. Search existing lessons before similar work.
2. apply already-proven checks.
3. record repeatable symptom/root cause and regression evidence.
4. promote repeated defects into safeguards only with authorization.
5. avoid needless new skills.

## Output
Actual findings, evidence, limitations and next authorized action. This skill never changes user-approved theory, role permissions or approval policy.
