# plan-task

## Procedure
1. For Git projects check `harness/common/branch_authority.py status` before choosing any development/integration target; never guess `main`, and stop if policy is missing. Read approved CRITERIA and the Implementation Plan/GOALMAP and confirmed use class, actual scale, trust boundaries, proportionate safeguards and explicit exclusions.
2. Read **full applicable Human-accepted decision records and source messages**, not just prior summaries. In an active optional Discussion Job, use the on-demand record-decisions skill when a Human settles a decision; no recording obligation outside that context. Follow current ACCEPTED entries, check supersession, capture complete source references and label missing/unverified records rather than inventing them. Keep approved CRITERIA WHAT/WHY distinct from accepted domain/operational HOW. Never assume a Discussion Job is mandatory.
3. Choose one approved Implementation Plan GOAL (observable outcome with linked CRITERIA IDs) and simplest implementation that meets its measurable acceptance and safety constraints; no speculative enterprise hardening or future-market infrastructure.
4. Define scoped tasks and tests with concrete prerequisites; mark out-of-scope "nice to have" as suggestions, not must-pass.
5. For the chosen Goal and each Task, preserve direct links to applicable **complete accepted decisions** and document COVERAGE (all relevant chosen steps addressed), CONFLICTS (active directions contradict), and FEASIBILITY (verified host/tool dependencies vs UNVERIFIED). A short Plan line is only orientation; the full Decision is the implementation reference. Never silently adopt superseded decisions or compress an expert algorithm into a topic heading.
6. Detect OPEN/STALE gaps and overengineering **and** underscoping for approved commercial/market scale.
7. Submit to Reviewer for goal/scope fidelity. Present the human a compact result/non-goals/risks summary, not a required technical diff or P1/P2/P3 deep dive.

## Output
Actual evidence, limitations and next authorized action. Never silently change approved theory.
