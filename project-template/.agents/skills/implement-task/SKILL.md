# implement-task

## Procedure
1. Validate task/goal and profile.
2. inspect changes and snapshot.
3. reload optional relevant knowledge.
4. make smallest compatible change.
5. run available checks and actual host tests.
6. debug reproducibly.
7. deliver scoped evidence, report unverified gaps.

## Output
Actual findings, evidence, limitations and next authorized action. This skill never changes user-approved theory, role permissions or approval policy.
