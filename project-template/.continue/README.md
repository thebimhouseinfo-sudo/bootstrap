# Continue adapter

Project .continue/rules/00-bootstrap.md is a workspace rule; .continue/rules/roles/*.md are optional task-specific role prompts. .continue/config.yaml is a starter and needs a user-selected model/provider. Run cn --config ./.continue/config.yaml or choose the local configuration in Continue, then check rule loading.

Continue rules do not create native isolated named subagents. Actual tool/model/hook/approval capabilities require separate verification.
